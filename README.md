# Vencimientos de Personal

App (PWA) que muestra el semáforo de vencimientos de documentación leyendo la Hoja de Trabajo HPS (Excel).

- No contiene datos: el Excel se elige en cada uso y se lee dentro del navegador del dispositivo.
- No envía ni guarda datos en ningún servidor. El "service worker" solo guarda la app para que abra sin señal.
